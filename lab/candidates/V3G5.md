## Ce qui change dans le code

### 1. Mesures (bloc `lab`, sans filtre)

Elles viennent de `docs/next/v3-criteres-m23.md` §2-3 et sont codées dans `deduce/holes.py`.

- `cells` : cases de la pose de référence, imports compris.
- `full_n_rows` : lignes dont chaque créneau est du nucléaire.
- `nuclear_share` : cases de nucléaire / `cells`. Elle n'était pas dans la spec : je l'ai ajoutée pour le squelette.
- `cells_per_decision` : `cells` / poids des décisions (poids de K) ; `null` sans décision.
- `holes = {n, unique, contested, types}` :
  - un trou est une suite de 1 ou 2 cases sûres d'une ligne, fermée de chaque côté par une brique météo ou le bord (une brique au moins) ;
  - ses types sont les domaines de la vue (`View.dom`), imports regroupés en `I` ;
  - **unique** : un type au point fixe du niveau 1 ;
  - **contesté** : au moins 2 types au point fixe, et une étape du tour qui le tranche est de niveau ≥ 2, fixe un échange ou pose un import ;
  - `types` : types au point fixe de chaque trou contesté.
  - Le point fixe du niveau 1 est lu dans la trace complète, sans 2e déduction : c'est le dernier tour avant la 1re étape de niveau ≥ 2, puisque la boucle essaie toujours le niveau 1 d'abord. Le solveur expose pour cela un crochet `Solver.observe` (vue de chaque tour), sans autre effet.
- **Calage sur les grilles citées par la spec** : 8 sur 8 conformes.
  - Contestées : c n°10, v3g3-a n°16, rampe n°10.
  - Tranchée trivialement : v3g3-b n°12.
  - 3 trous à gaz seul et C/D = 3,1 : a n°3.
  - 7 trous uniques : v3g3-b n°14.
  - 50 cases et 4 lignes de nucléaire : v3g3-b n°13 ; 5 lignes : rampe n°14.
- **Agrégats `.stats.json`** : `cells`, `cells_bands` (≤ 28 / 29-39 / ≥ 40), `hard_cells_bands` (Difficile + Expert), `full_n_rows`, `nuclear_share`, `nuclear_under_half`, `cells_per_decision`, `holes`.
- **`rerate_lots.py`** les recalcule. Il a été relancé sur les 9 lots actifs : `v3-jouer-a/b/c`, `v3g3-jouer-a/b`, `v3g4-jouer-a/b/c`, `v3g4-rampe`. **Aucune note n'a changé** (180 grilles).

### 2. Squelette desserré (deux options d'entrée, éteintes par défaut)

- **`max_nuclear: [lo, hi]`** : la pose de référence garde au plus cette part de nucléaire.
  - Le plafond est tiré par grille ; 1 veut dire sans plafond. Il est gardé dans `lab.nuclear_cap`.
  - C'est une contrainte CP-SAT, `100 × cases N ≤ plafond × cases posées`. Si elle est infaisable, la pose est refaite sans plafond.
  - Je l'ai choisie parce que c'est le plus simple : une contrainte linéaire, sans toucher aux rangs.
- **`allow_one_plant`** : le rejet `one_plant` est levé. Le rejet `trivial` (une seule clé, sans échange ni STEP) reste.

### 3. Écrit pour la 1re consigne, puis éteint

Aucun lot ne s'en sert. Tout est testé.
- `hole_types` (entrée) : la référence tire le type de chaque trou parmi ceux qui y tiennent, au lieu du moins cher.
- `min_with_contested` (quota doux, jamais un rejet) : tant qu'il manque, une grille Moyen ou plus sans trou contesté attend une fois sur deux. C'est le « poids ×2 ».
- `filler_cells` : rejet `filler` d'une Difficile ou Expert d'au moins N cases.
- `min_per_rating` accepte `{note: n}`. Il sert au témoin (voir plus bas).

- **Mineurs de la review v3-gen-4** (`min_per_mix` avant les plafonds, jumelles par paire) : non traités. La nouvelle consigne demande de ne plus ajouter de quotas.
