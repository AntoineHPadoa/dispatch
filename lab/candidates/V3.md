## Taux de rejet `infeasible` (C1)

- **Mesure** : `rejects_by_family` (nouveau dans `.stats.json`), tirages sans solution de référence par famille.
- **Essai avant les lots** : 80 tirages par famille, configurations des lots `nuit-*`, famille imposée. `midi_solaire` 0 %, `surplus_midi` 4 % (3 sur 80) ; `pointe_soir` et `plateau_hiver` 0 %.
- **Dans les 4 lots** : 0 tirage `infeasible` sur 636 (`midi_solaire` 0 sur 53, `surplus_midi` 0 sur 83).
- **Décision** : bien sous le seuil de 50 %, `silhouettes.py` n'est pas modifié. Taux avant = taux après.
- **Lecture** : la solution de référence est cherchée sur `Puzzle`, qui ne pose qu'au-dessus de la météo, avec l'inventaire libre et les imports en secours. Elle n'est rejetée `infeasible` que si aucune variante (avec ou sans exports) ne tient. Les rejets restent dominés par `one_plant`, `too_many_clues` et les quotas, comme pour les lots `nuit-*`.
