Hors périmètre
  • Animations et gestes : seul l’état figé d’un geste est capturé (glisser maintenu, premier toucher).
  • Le lab, la tablette et le mode sombre ne sont pas montrés.
  • 7 vues portent le badge « grille fictive » : grille écrite pour la galerie (ids 901+), jamais publiée. Le verdict juste n’est montré que sur de vraies grilles.
  • Date du jeu figée après le dernier bulletin : la fiche du jour est le dernier bulletin publié.
