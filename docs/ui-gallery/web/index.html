Dispatch à l’écran

Le jeu à 1280 px, joué à la souris. Chaque image est une capture du vrai jeu, rejouée par web/scripts/ui-gallery.mjs ; aucune n’est retouchée. Cliquer une capture l’agrandit en pleine résolution.

Hors périmètre
  • Animations et gestes : seul l’état figé d’un geste est capturé (glisser maintenu, premier toucher).
  • Le lab, la tablette et le mode sombre ne sont pas montrés.
  • 10 vues portent le badge « grille fictive » : grille écrite pour la galerie (ids 901+), jamais publiée. Le verdict juste n’est montré que sur de vraies grilles.
  • Date du jeu figée après le dernier bulletin : la fiche du jour est le dernier bulletin publié.
