Dispatch sur téléphone

Le jeu à 375 px, joué au toucher, avec trois vues témoins à 320 px. Chaque image est une capture du vrai jeu, rejouée par web/scripts/ui-gallery.mjs ; aucune n’est retouchée. Cliquer une capture l’agrandit en pleine résolution.

Hors périmètre
  • Animations et gestes : seul l’état figé d’un geste est capturé (glisser maintenu, premier toucher).
  • Le lab, la tablette et le mode sombre ne sont pas montrés.
  • 14 vues portent le badge « grille fictive » : grille écrite pour la galerie (ids 901+), jamais publiée. Le verdict juste n’est montré que sur de vraies grilles.
  • Les vues sur une vraie grille, l’accueil et le dossier sont prises sur le build de prod, tel que publié le jour de la capture. Seules les grilles fictives passent par un build de galerie, à la date figée après le dernier bulletin.
