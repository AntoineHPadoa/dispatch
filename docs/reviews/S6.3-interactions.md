# Dispatch — liste fixe des interactions

Référence pour chaque tour de vérification : chaque ligne se joue dans un vrai navigateur (Chromium piloté par Playwright), à la souris à 1280 px et au tactile à 375 px, puis se note attendu / obtenu dans le rapport du tour.

| # | Geste | Contexte | Résultat attendu |
|---|---|---|---|
| **Accueil et navigation** | | | |
| I1 | Clic « Jouer » sur la carte « Grille du jour » | accueil | ouvre la grille du jour (`#/grille/<id>`) |
| I2 | Clic sur une carte de tutoriel ou de grille notée | accueil | ouvre cette grille ; titre et étiquette de niveau identiques à la carte |
| I3 | Clic « Toutes les grilles » | écran de jeu, partie commencée | retour à l'accueil ; la carte passe à « En cours » / « Reprendre » |
| I4 | Précédent / suivant du navigateur | accueil ↔ grille | navigation cohérente, l'état de la partie est conservé |
| I5 | Clic « Imprimer toutes les grilles » | accueil | aperçu d'impression de toutes les grilles, une par page |
| I6 | Adresse inconnue (`#/grille/99`, `#/xyz`) | barre d'adresse | accueil affiché, pas d'écran vide ni d'erreur |
| **Choisir et poser** | | | |
| I7 | Clic sur une centrale du carnet | écran de jeu | ligne surlignée ; message d'aide de pose |
| I8 | Glisser à la souris d'une case à une autre sur une ligne | centrale choisie, place libre | aperçu vert pendant le glisser, message « la pose tient » ; au relâcher, barre posée, carnet mis à jour |
| I9 | Glisser hors de la silhouette | centrale choisie | aperçu rouge et raison en clair ; au relâcher, rien n'est posé, la raison reste affichée |
| I10 | Deux touchers : case de départ, puis case d'arrivée | tactile, centrale à barre | 1er toucher : ancre visible, message « touche maintenant la case d'arrivée » ; 2e : barre posée |
| I11 | Survol à la souris après un premier clic | souris, ancre posée | aperçu de la barre jusqu'à la case survolée |
| I12 | Un toucher | pièce d'une case (TAC, import) | pièce posée immédiatement |
| I13 | Glisser sur une longueur non permise | centrale à barre (ex. 2 créneaux de nucléaire) | refus avec la raison (« doit faire 3 à 6 créneaux ») |
| I14 | Poser au-delà de l'inventaire exact | tutoriel, barre déjà toutes posées | refus avec la raison (« plus de barre … dans l'inventaire ») |
| I15 | Poser par-dessus des pièces posées | place occupée | aperçu « remplace … » ; pièces recouvertes retirées, nouvelle pièce posée, une seule étape d'annulation |
| **Retirer et revenir** | | | |
| I16 | Gomme puis toucher une pièce | pièce posée | pièce retirée, message « … retirée » |
| I17 | Gomme puis toucher une case vide | case vide | message « Aucune centrale sur cette case », rien ne change |
| I18 | Clic droit sur une pièce | souris | pièce retirée, pas de menu contextuel du navigateur |
| I19 | Appui long sur une pièce | tactile | pièce retirée, aucune pose déclenchée |
| I20 | Annuler | après une action / sans action | dernière action défaite ; bouton grisé quand il n'y a rien à annuler |
| I21 | Recommencer | partie commencée | grille remise à zéro ; « Annuler » rétablit la partie |
| **Échanges** | | | |
| I22 | Toucher une pastille d'export | voisin, ligne de 1 bloc | 0 → 1 → 0 ; la silhouette monte d'une case puis redescend |
| I23 | Exporter sur une colonne qui importe déjà | ligne saturée par un import | refus avec la raison (ligne saturée) |
| I24 | Choisir « Import » et toucher une case | voisin | case importée posée, compteur du carnet mis à jour |
| I25 | Toucher une pastille à cadenas | flux publié | rien ne change (flux verrouillé), libellé accessible explicite |
| **STEP** | | | |
| I26 | Choisir STEP, toucher un créneau puis un créneau plus tard | grille avec STEP | message « Pompage à … » puis paire posée ; ▲ ajoute une case, ▼ en retire une |
| I27 | Toucher un créneau plus tôt pour le turbinage | pompage en attente | refus « le turbinage vient après le pompage » |
| I28 | Toucher le dernier créneau pour pomper | STEP choisie | refus « pas de pompage sur le dernier créneau » |
| I29 | Poser une paire de plus que publié | toutes les paires posées | refus « toutes les paires STEP sont déjà posées » |
| I30 | Toucher une étiquette ▲ ou ▼ (ou gomme sur la case pompée) | paire posée | paire retirée |
| **Indices et verdict** | | | |
| I31 | Poser ce qui respecte / contredit un indice | indice prix, relevé, programme, flux | pastille verte « vérifié » ; rouge « contredit » ; compteur « k sur n vérifiés » à jour |
| I32 | Rendre une pièce invalide (retirer l'export sous elle) | pièce posée sur une case d'export | pièce hachurée rouge, jamais supprimée d'office, message clair |
| I33 | Couvrir toute la silhouette avec la bonne composition | fin de partie | bannière « Programme bouclé », durée, « Grille suivante » et « Imprimer » |
| I34 | Couvrir toute la silhouette avec une mauvaise composition | fin de partie fausse | message clair, pas de bannière |
| I35 | Clic « Grille suivante » | grille terminée | ouvre la grille suivante ; sur la dernière, retour aux grilles |
| I36 | Déplier « Tous les indices en texte » | grille avec indices de créneau et de journée | liste complète affichée |
| **Impression, rechargement, clavier** | | | |
| I37 | Clic « Imprimer » | écran de jeu (ordinateur) | dialogue d'impression de cette grille seule (feuille A4, style papier) |
| I38 | Recharger la page | partie en cours / terminée | pièces, exports, STEP restaurés ; chrono qui continue ; grille terminée reste terminée |
| I39 | Flèches, Entrée deux fois, Suppr, Échap | plateau focalisé au clavier | curseur visible, pose, retrait, annulation du geste |
| **Ajoutées au tour 2** | | | |
| I40 | Clic « Grille suivante » (ou « Imprimer ») de la bannière | juste après la dernière pose faite sur le plateau, sans autre clic | la grille suivante s'ouvre au 1er clic (l'impression part au 1er clic) |
| I41 | Glisser une barre, puis deux touchers ailleurs | tactile | au 1er toucher, l'ancre seule et « touche maintenant la case d'arrivée », sans aperçu |
| **Ajoutée au tour 3** | | | |
| I42 | Balayage vertical sur le plateau (aussi depuis la bande vide au-dessus, une pastille, avec la gomme ou la STEP) | tactile, centrale à barre choisie | la page défile, aucun aperçu, aucun message de refus, rien n'est posé, retiré ni pompé |
